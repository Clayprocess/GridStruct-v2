# GridStruct V2 0.2.4

## 截图与吸附

- 在 Excel 单元格上按下并拖动，即可像在工作表里一样选中一块矩形区域。选区会包含触及的整个合并单元格，拖出可见区域时停在最后一格。单击可选一格，拖动选区边角可按格调整，按住 `Alt` 可自由框选或调整。
- Excel 按格截图会保留四周框线。即使 Windows 使用 125% 缩放，裁剪仍沿用 Excel 提供的物理像素边界。
- 改进了 Office、Zoom、Windows 任务栏和 Electron 应用中的元素吸附。截图开始时预取表格元素，在同一个大框内移动鼠标也会继续查找指针下的小控件。用触控板滚动时，短时间内连续触发的滚轮事件只切换一层。

## 其他修复

- 标注画到一半时切换工具或按 Esc，会先保留当前笔画。退出或转为长截图时，已有的未保存标注会触发退出确认。
- 修复表格网格线拖动被打断时重做报错，以及重新分析失败时丢失手工改字的问题。
- 设置保存失败时会尝试恢复此前生效的快捷键和开机自启设置，并提示需要手动恢复的项目。

## 验证与使用

Windows Excel 取样确认了普通格与合并格的边界。100% 和 125% 缩放的离屏测试已逐像素核对裁剪结果，Windows 鼠标操作的 9 项实测仍在跟踪。[验收记录 #66](https://github.com/Clayprocess/GridStruct-v2/issues/66)

下载 Windows 便携 ZIP，完整解压到可写目录，保留同目录的 `_internal` 文件夹，双击 `GridStruct-V2.exe` 启动。
