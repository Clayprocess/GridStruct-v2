GridStruct V2 0.2.1：修复 0.2.0 被 Windows Defender 误报为木马的问题，功能与 0.2.0 相同。

## 下载与使用

下载下方的 `GridStruct-V2-v0.2.1-portable.zip`，完整解压到可写目录，双击 `GridStruct-V2.exe`。无需安装 Python，不需要管理员权限。程序常驻系统托盘，按 `Ctrl+Alt+S` 截图，右键托盘图标打开“识别文档…”和设置。已在用 0.2.0 的，直接用新文件夹替换程序，把旧目录的 `user-data/` 复制过来即可保留配置和贴图。

## 修复

- 0.2.0 的 `GridStruct-V2.exe` 会被 Windows Defender 报 `Trojan:Win32/Bearfoos.A!ml` 并隔离。这是机器学习误报，程序本身没有变化。本版改为用自行编译的 PyInstaller 启动程序打包，并给两个 EXE 写入版本信息（右键“属性 > 详细信息”可见），在报毒的电脑上实测已不再报。

## 注意

此包仍未做代码签名，首次运行可能出现 SmartScreen“已保护你的电脑”提示，点“更多信息 > 仍要运行”即可。杀毒软件的判断会随病毒库更新变化，若再被报，请反馈被报的文件名和检测名。
