GridStruct V2 0.2.1 发布说明草稿。本文不代表版本或安装包已发布；发布前需核对最终功能与验证结果。

## 构建调整

- 针对 v0.2.0 的 `GridStruct-V2.exe` 被 Defender 检测为 `Trojan:Win32/Bearfoos.A!ml` 的反馈，构建流程改为从源码编译 PyInstaller 引导程序，并与同版本官方 wheel 的引导程序比较哈希。
- 两个 EXE 写入版本信息（右键“属性 > 详细信息”可见）；构建清单记录引导程序哈希。
- 这些调整不证明原检测是误报，也不代表 Defender 或 SmartScreen 已通过验收。是否仍出现检测或提示，需要对最终安装包在目标 Windows 环境验证。

## 运行提示

安装包仍未做代码签名。遇到 Defender 隔离或 SmartScreen 提示时，请先核对下载来源和文件完整性，并保留文件名、检测名及构建信息供排查；不要仅凭本说明忽略系统提示。若认为检测有误，可通过 Microsoft 安全智能文件提交入口申请复核。

## 功能变更

识别窗口的缩放拖动、窗口状态、默认全文、表格整页预览及方向分类调整，见 PR #46；发布前需按实际合入内容补齐验收说明。
