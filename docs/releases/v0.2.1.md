# GridStruct V2 0.2.1

## 功能与修复

- 截图 OCR 在工具条下方直接显示可编辑全文，与原图双向定位；支持段落、原样换行、一行排版，低置信度波浪线与 F8 跳转。复制文字使用编辑后的全文并结束截图；文字识别窗口同步采用全文编辑方式。
- 修复刚画完标注后改色，下一笔或切换工具仍用旧颜色的问题；手动选中的旧标注仍可独立改样式。
- 窗口与控件吸附改用常驻查询线程；修复鼠标静止时不再精化、查询完成与超时处理竞争、超时残留旧框的问题。
- 修复多屏边缘的选区描边缺失，保留跨屏接缝和混合缩放下的局部重绘；拖动选区时隐藏手柄和工具条，松开恢复。
- 鼠标离开截图遮罩进入工具条时收起取色放大镜，返回后恢复。移除标注阶段重复的放大镜、取色入口和“更多”菜单；工具条仅显示撤销，重做使用 Ctrl+Y。框选阶段仍可按 Shift 切换颜色格式、按 C 复制颜色并结束截图。
- 修复识别窗口缩放拖动、画布替换及窗口状态恢复；完善表格整页预览，停用可能将英文长行翻转的 OCR 方向分类。

## 构建调整

- 发布流程在 Windows runner 上从源码编译 PyInstaller 引导程序，并与同版本官方 wheel 比较哈希。
- 两个 EXE 写入版本信息；构建清单记录依赖、引导程序和资源哈希。便携包完整解压后即可使用，无需另装 Python。
- 此调整针对 v0.2.0 的 Defender `Trojan:Win32/Bearfoos.A!ml` 检测反馈，不证明原检测是误报，也不保证消除 Defender 或 SmartScreen 提示。安装包仍未签名。

## 验证与限制

- 合并后的源码离屏冒烟 36/36 通过，包含本地离线 OCR、放大镜隐藏与恢复、颜色快捷键、撤销和 Ctrl+Y 重做。
- 合成多屏绘制 192 案例、选区与 DPR 32 案例、截图退出 3/3、吸附线程及 OCR 卡片回归通过；已检查明暗工具条渲染。
- 发布流程另执行 Windows 识别窗口回归，并在构建时校验模型与图标哈希、Qt 原生 DLL 加载及 ZIP CRC。
- 重复文字场景下，撤销全文编辑仍可能低概率出现对应关系错配；按已确认的范围，此次暂不修复。
- 离屏及合成多屏检查不等于真实 Windows 桌面验收。真实多屏、混合缩放、外部控件吸附手感及最终安装包的 Defender/SmartScreen 检测仍需目标电脑验证；构建清单中的 runtime_verified 保持 false。

若遇到隔离或启动提示，请保留下载来源、文件名、检测名及构建信息供排查。完整保留 EXE 旁的 _internal 目录；个人配置保存在 user-data，发布包不包含用户数据。
