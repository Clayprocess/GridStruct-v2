GridStruct V2 首个版本：Windows 本地截图、标注、贴图与 OCR 工具，交互对标 PixPin。

## 下载与使用

下载下方的 `GridStruct-V2-v0.1.0-portable.zip`，完整解压到可写目录，双击 `GridStruct-V2.exe`。无需安装 Python。程序常驻系统托盘，按 `Ctrl+Alt+S` 截图。配置和未关闭的贴图保存在同目录的 `user-data/`，移动整个文件夹即可迁移。

## 包含功能

- 截图：框选、窗口/元素吸附、选区微调，浮动工具条分主区和次区
- 标注：矩形/椭圆合并的几何工具、箭头、画笔、直线、折线、文字、序号、马赛克、高亮、橡皮擦、放大镜，支持撤销重做
- 输出与取色：复制、保存 PNG/JPG、贴图；Hex/RGB/HSV 取色
- 图片和文字贴图：缩放、置顶、不透明度、鼠标穿透，Space 进入标注，退出后恢复
- 长截图：手动/自动滚动，纵向/横向拼接
- 本地 OCR：PP-OCRv6 small 模型随包提供，识别时不联网
- 设置与托盘：明暗/系统主题、开机启动

本版本还修复了 #6 至 #10：撤销删除后的叠放顺序、输入中文字的样式调整、序号撤销后跳号、Shift 方形选区在屏幕边缘被裁、贴图会话缺字段时恢复失败。

## 注意

此包由 GitHub Actions 在 Windows runner 上自动构建，只校验了资源完整性和 Qt 原生 DLL 能否加载，**尚未在真实 Windows 电脑上运行验收**。遇到问题请提 issue。
