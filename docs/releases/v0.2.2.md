# GridStruct V2 0.2.2

## 功能与修复

- 修复 #53：OCR 将相邻列文字识别成一个框时，按逐字位置沿列线分格；账号、户名、币种和利率可回到各自列。合并格内不切分，拖线和切换网格时重新分配。
- 没有逐字位置、位置与原文不匹配或几何无效时，退回按字宽估算。切分结果标为待复核；逐字位置与估算均不能保证识别正确，请对照原图核对重要字段。
- 修复先确认或修改切分后的格子、再拖线／合并格／删除列线时的原文丢失或重复。保留人工校正的原区域规则，逐字排除已替代的原文；撤销、重做可恢复。
- 修复字框跨线后二次按整框中心归列，以及文字全在一侧时仍落错列的问题；非法逐字数据不再使分格崩溃。
- 切分和低置信度同时存在时，悬停提示与 Excel 批注同时说明两种原因。复制、CSV、HTML 和 XLSX 使用复核后的当前表格；XLSX 保持文本单元格，不转换长数字、前导零或公式样式文字。

## 验证与限制

- Linux 离屏针对性检查：808 组逐字定位／估算回退、确认／修改、双向拖线、合并／删除列线、撤销／重做和恢复网格场景；校验实际剪贴板 TSV／HTML、XLSX 文本及待复核批注。
- 表格真实本地 OCR 合成样图、整页和多页分析、人工校正、导出、明暗界面检查；OCR 数据持久化、贴图、复核、后台任务、窗口、截图区域／遮罩／退出和吸附线程回归。
- Windows 发布工作流另执行离线 OCR 窗口回归及跨列表格数据回归，然后构建便携 ZIP、验证资源哈希、Qt 原生 DLL 加载和 ZIP CRC。
- 原始客户截图未用于本次复测；本次证据来自合成图片与脱敏文字。未进行真实 Windows 桌面、Excel/WPS 应用粘贴或 Defender／SmartScreen 实测，构建清单的 runtime_verified 保持 false，安装包仍未签名。
- v0.2.1 已说明的重复文字全文编辑撤销对应关系限制仍保留；本次不改变该范围。

完整解压便携包并保留 EXE 旁的 _internal 目录。发布包不含 user-data；重要账号、户名与金额在复制或导出前请对照原图复核。
