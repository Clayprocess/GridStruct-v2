# GridStruct V2 0.2.3

## 功能与修复

- 修复元素吸附选不中整张表格：Chrome、Edge 等浏览器的点命中会直接返回最深的文字，跳过表格、行等容器，滚轮层级只有“文字 → 单元格 → 整页”。现在沿父对象补回被跳过的层级，滚轮可依次切到单元格、行、整张表格、正文和窗口。
- 修复 #56：补全父层级在 Edge 里每次约 200ms，导致框跟随变慢，甚至整个窗口被降级为只吸附整窗。改为两段式：先按点命中结果立即出框；鼠标停住后再在后台补全父层级，鼠标一移动就中断，同一元素补过后直接复用。
- 慢窗口降级只计算点命中本身的耗时；偶尔卡住的窗口 30 秒后重新尝试元素吸附，不再整次运行都只能吸附整窗。
- 后台补全或重试父层级时，保持滚轮已经选中的框，不会自动跳到其他层级；补全中途失败时先用已找到的层级，下次再重试。

## 验证与限制

- Linux 离屏及模拟 MSAA 检查：吸附点命中与父层级补全 7 项、截图退出 3/3 通过，包含浏览器式跳层、局部跳层、同尺寸包装层、补全中断与缓存、补全失败重试、滚轮层级保持和引用释放。
- 未在真实 Windows 的 Chrome/Edge 中验证吸附手感和耗时；构建清单的 runtime_verified 保持 false，安装包仍未签名。

完整解压便携包并保留 EXE 旁的 _internal 目录。发布包不含 user-data。
