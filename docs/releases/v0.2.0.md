GridStruct V2 0.2.0：在截图工具之外，加入本地表格识别和文档识别，面向审计回函等需要把图片表格录入 Excel 的场景。

## 下载与使用

下载下方的 `GridStruct-V2-v0.2.0-portable.zip`，完整解压到可写目录，双击 `GridStruct-V2.exe`。无需安装 Python，不需要管理员权限。程序常驻系统托盘，第一次启动会弹出提示；按 `Ctrl+Alt+S` 截图，右键托盘图标打开“识别文档…”和设置。

## 新增

- 表格识别：截图工具条、图片贴图右键、文字识别窗口都能进入。自动生成表格网格，左侧对照原图拖动、增删行列线，右侧实时重新分格；低置信度格子标为待复核，`F8` 逐个跳转。复制时同时放 TSV 和 HTML，粘贴到 Excel/WPS 保留合并单元格；导出 xlsx（按文本写入，待复核格标黄加批注）、CSV、HTML。
- 识别文档：托盘菜单或自定义热键打开图片、PDF、多页 TIFF，逐页校对后合并为一张表，续页重复表头自动去掉。加密、损坏或无法读取的文件会说明原因并跳过。
- 文字识别窗口简化为按行、按段、全文三种整理方式，可直接修改。
- 表格结构模型 SLANet_plus 随包提供，识别全程在本机完成，不联网。

## 改进

- 关闭的贴图，其图片会从 `user-data/pins/` 中清理。
- 截图交互：连续落笔、焦点恢复、Esc 退出与未保存确认等细节调整。

## 注意

此包由 GitHub Actions 在 Windows runner 上自动构建，构建时校验了模型哈希和 Qt 原生 DLL 能否加载。自动分格对有框线的截图表格效果最好，无框线表、倾斜扫描件往往需要手工调整网格；识别结果需人工确认后使用。
