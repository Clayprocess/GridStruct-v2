GridStruct V2 0.2.0：在截图工具之外，加入本地表格识别和文档识别，面向审计回函等需要把图片表格录入 Excel 的场景。

## 下载与使用

下载下方的 `GridStruct-V2-v0.2.0-portable.zip`，完整解压到可写目录，双击 `GridStruct-V2.exe`。无需安装 Python，不需要管理员权限。程序常驻系统托盘，第一次启动会弹出提示；按 `Ctrl+Alt+S` 截图，右键托盘图标打开“识别文档…”和设置。

## 新增

- 表格识别：截图工具条、图片贴图右键、文字识别窗口都能进入。自动框出有线表格，框外的标题和说明不进表；找不到有线表时按裁掉空白边后的整块内容分析。点“框选表格”（`R`）可调整、删除或补画框，改框后只重算结构，不重跑 OCR；没动过的表保留网格和改字。一张图多张表可切换校对。左侧对照原图拖动、增删行列线，右侧实时重新分格；低置信度格子标为待复核，`F8` 逐个跳转。
- 多表输出：复制当前表时同时放 TSV 和 HTML，粘贴到 Excel/WPS 保留合并单元格；导出 xlsx 一表一个工作表，按文本写入，待复核格标黄加批注；网页依次列出各表。CSV 仅支持单张表，多张表时请用 xlsx 或网页。
- 识别文档：托盘菜单或自定义热键打开图片、PDF、多页 TIFF，逐页框选和校对；可输入页码回车跳转，无效或越界输入只提示。导出工作表按“第N页-表M”命名。跨页续表默认不合并，在下一页第一张表上勾“接上一页”后才接到紧邻上一页的末表，相同的重复表头自动去掉；上一页没有可接的表时单独导出并提示。复制时包含接上的续表。加密、损坏或无法读取的文件会说明原因并跳过。
- 文字识别窗口简化为按行、按段、全文三种整理方式，可直接修改。
- 表格结构模型 SLANet_plus 随包提供，识别全程在本机完成，不联网。

## 改进

- 会话保存成功后清理不再引用的贴图图片；备份引用的图片保留，备份无法完整读取时暂停图片清理。
- 截图交互：连续落笔、焦点恢复、Esc 退出与未保存确认等细节调整。

## 注意

此包由 GitHub Actions 在 Windows runner 上自动构建，构建时校验了模型哈希和 Qt 原生 DLL 能否加载；这些检查不代表已完成真实 Windows 电脑上的交互验收。自动框表只认有线表，无线表、三线表需要手动补框，倾斜扫描件往往需要手工调整网格；识别结果需人工确认后使用。
