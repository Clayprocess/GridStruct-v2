# 表格校对工作台：原型确认与实现记录

本次将独立 HTML 中确认的方案迁移到现有 PySide6 表格识别窗口。基线为 `ca9d3da97f6721b614b6febb364fa242b2ecb8b8`，不涉及截图流程扩展、#70、发布或安装包。

## 最终采用的交互

| 区域 | 已确认决策及对应实现 |
| --- | --- |
| 布局 | 初次进入左 45%、右 55%，分隔条仍可拖动。两侧工具在各自画布左上方真正悬浮，不预留一整行空白。右工具固定展开；不再采用中途讨论过的悬停入口。 |
| 工具分组 | 完整圆角外壳内，用浅底色圆角组块分区；组内不增加边框。控件圆角统一 9px，图标使用已有 Lucide SVG、16px、2px 线宽。窄面板优先将历史和合并按钮收成图标，保留提示，不折成第二行。 |
| 左侧原图 | 边缘提供加线入口，直接拖分隔线，四角可调整表格范围。横线和竖线连续添加，重复点击同一按钮退出；删除一次退出，删除按钮再次点击也退出，保留 Esc。 |
| 线距 | 手动增线、拖线、规则网格、结构模型与吸附整理统一为 5 个原图像素。模型过近内部边界删除并重映射合并格，不把伪窄格强行撑宽，外框保留。 |
| 线条预览 | 加线显示蓝虚线；右键菜单悬停加线也预览。删除采用沿原线的 1px 红细折线、8px 周期、2px 起伏；只有删除模式或删除菜单悬停才显示。 |
| 光标 | 透明细线铅笔/橡皮，行列头使用选择箭头。遵循最终要求的轻量形态；产品使用自绘光标，不分发原型里曾使用的本机 Microsoft Excel 私有资源。 |
| 右侧表格 | 原生表格嵌入缩放画布，四周留白，默认居中，连续背景表示选区。点击行列头选整行列，拖动选择多行列，单元格矩形拖选，接近画布边缘自动滚动。 |
| 视图操作 | 空白拖动、Space+拖动平移；格内编辑保留空格和拖选语义。滚轮以指针为锚点缩放；右下与左侧共用缩放栏，支持减号、比例、加号、适应窗口；比例点击回100%，适应恢复居中。视图变换不写入内容撤销历史。 |
| 复核 | 当前格、待复核数、下一处、确认并下一处在右上工具栏金额入口左边。F8 下一处，Ctrl+Enter 提交/确认后下一处，左图高亮跟随。 |
| 金额 | 选择列或区域后自动识别原格式，直接在原表显示原值和目标值；应用时统一逗号千分位、句号小数点并保留小数位。取消不改数据，整次应用一次撤销。 |
| 歧义 | `1,234`、`1.234` 等存在多个解释的值标记但不修改。非金额、前导零、日期、公式、百分比跳过；不根据邻格猜测。带币种前后缀和印度分组暂时跳过，不引入币种推断。 |
| 预览中断 | 预览只存展示角色，不写正文。锁定结构编辑、选区、缩放与输出；Esc/取消退出预览，Ctrl+Z先取消预览，翻页/换表先取消，不应用未确认转换。 |
| 范围重分析 | 直接拖角的成功分析迁移人工校对；范围、网格、文字及源 token 同一快照撤销/重做。失败沿用原有恢复路径。其他表正在编辑时不销毁输入框。 |
| 多页与输出 | 左下页码导航与缩放栏同位置风格；接上一页在右上工具组中，首页禁用。复制和导出复用原有真实 TSV/HTML/XLSX 输出，保留合并格及未复核提示，导出按钮去省略号。 |
| 明暗模式 | 表格工作台使用局部 tokens，强调辅助文字、网格、待复核和选区的对比，不改变原图纸面，不改变其他窗口主题。 |

## 已被后续决策替代的方案

- 来源格式手动选择、独立确认弹窗 → 自动识别、原表预览、一次应用。
- 工具栏全宽占位、右下工具栏、悬停展开入口 → 左右同位置、内容宽度、上方固定悬浮。
- 删除粗红线、舒展波浪线 → 细密批改感红折线。
- 单独复位按钮 → 统一缩放栏中的适应窗口。
- 独立分组描边、较深底色 → 连续外壳、浅底色组块、统一圆角。

## 验证边界

在 Mac mini 上使用隔离 Python 环境验证。`tools/check_table.py` 包括本地 OCR/SLANet 对合成图的真实推理；交互脚本是 PySide6 离屏事件验收，不等同于 Windows/Excel/WPS 真实桌面验收。

`tools/preview_table_workbench.py` 是显式开发预览入口：调用真实 TableDialog，输入合成办公用品表，不启动截图热键或模型任务。`--render` 可输出明暗主题图片。

目标 Windows 上仍需人工核对：系统 DPI、鼠标光标实际尺寸、拖选滚动手感、格内输入法、Excel/WPS 粘贴，以及实际业务图片的模型结果。
